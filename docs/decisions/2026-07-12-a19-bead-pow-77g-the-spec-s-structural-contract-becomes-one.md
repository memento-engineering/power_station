## A19 (2026-07-12) — bead `pow-77g`: the spec's structural contract becomes ONE exported string the brief RENDERS and the gate ENFORCES; the gate recognizes ordinal HEADINGS, scopes the step check to the plan body, and reads structure from PROSE

**Decision:** the deterministic `spec-validation` lane (A13(2)) was F'ing specs the LLM critics graded **A**. The tell is `pow-kzx`: a 56,195-character design that `plan-completeness` graded **A** ("every step names an exact file path, quotes exact before/after code blocks") and this lane graded **F** — `design: "## Implementation Plan" has no numbered steps` — because it carries ZERO lines matching the old `^\s*1[.)]\s` and instead opens each step with `### Step N — …`, the shape a plan with a fenced Dart block per step must take (a `1.` list item would have to indent every following block to stay inside the item). The gate rejected the plan's markdown dialect, not its content, and it rejected a dialect the brief never named. Four autonomous calls:
(1) **The structural contract becomes ONE exported string** — `kSpecStructuralContract`, which `buildSpecifyBrief` renders VERBATIM into the specify agent's own brief, carrying a COMPLETE exemplar spec (`kSpecExemplarAcceptance` + `kSpecExemplarDesign`) that is ROUND-TRIPPED through `specStructuralFindings` in test. A gate whose contract the brief does not state is a trap; a brief that states a contract the gate does not enforce is a lie. Making them one string, with the shipped exemplar proven against the gate that grades it, is the only shape in which neither can drift from the other. This is the bead's fix (a), and it is the load-bearing half.
(2) **The gate recognizes an ordinal HEADING (`### Step 1 — …`, `### 1. …`, `**Step 1:** …`) as a numbered step**, alongside the ordered-list item it already took. This is the bead's fix (b) taken only as far as its own tight-contract caveat allows: the ORDINAL stays MANDATORY, so a bulleted or prose-only plan — whose steps are neither ordered nor addressable — still fails LOUD. What changes is WHICH structures count as whole, never who decides.
(3) **The numbered-step check is SCOPED to the `## Implementation Plan` section's own body, and section lookup moves to `_proseOnly` output.** The old check scanned the WHOLE design for the ordinal, so a genuinely step-less plan passed whenever any `1.` appeared in another section — a false NEGATIVE the fix closes, so the gate bites harder here than it did before. Reading the section headings from prose extends A13(10)'s prose-not-quotation principle (already governing the placeholder fence) to the STRUCTURE check: a `## ` heading or a step ordinal quoted inside a fenced block is evidence, not structure. That is load-bearing for this pack, whose own specs quote all four headings verbatim.
(4) **`_placeholderPatterns` is DERIVED from the exported `kSpecPlaceholderTokens`**, which (1)'s contract enumerates. The brief had named three of the seven tokens the fence compiles (`TBD`, `appropriate error handling`, `similar to step`); the four it omitted — `TODO`, `implement later`, `fill in later`, `as needed` — are ordinary English an architect writes without thinking, so a good spec could park on a rule nobody stated. One list, banned and stated from the same source, cannot drift.
A13(2)'s posture is preserved exactly: the lane stays a deterministic `ServiceCapability` with no model and no judgement, still returns `{'grade','transport':'structural','rationale'}`, and still NAMES every missing element (guards LOUD — the new finding names both accepted ordinal shapes). A14(3) is untouched: a structural `F` is still a hard block to a human, never an auto-respec. The change removes the MANUFACTURED F's so the escalation arm fires only on real ones.
**Why:** of 7 beads in the 2026-07-11 opus wide run, 3 wedged on this lane rather than on any critic — good specs stuck at a structural gate independent of their quality, which is the most expensive kind of false block (the human unwinds a park that never named a real defect). The root cause was not the regex's strictness but the fact that the contract lived ONLY in the regex: the specify brief said "numbered steps" and the gate meant "a line matching `^\s*1[.)]\s` somewhere in the design," and nothing forced those two to be the same claim. Loosening the regex alone (the bead's fix (b) in isolation) would have closed this instance and left the trap armed for the next unnamed rule, which is why (1) — not (2) — is the amendment's centre. This is the `CLAUDE.md` D-H clause **Guards LOUD or GONE** applied to the gate itself: the numbered-step guard was loud, but its invariant was never NAMED to the agent it judged. Verified end to end against the live artifact: `pow-kzx`'s real 56,195-character design (0 `1.`-led lines) now returns EMPTY findings.
**Affects (if promoted):** power_station code: `packages/grid_assets/lib/src/code/specify.dart` (new public `kSpecPlaceholderTokens`, `kSpecExemplarAcceptance`, `kSpecExemplarDesign`, `kSpecStructuralContract` — all reaching the pack API through the existing `export 'src/code/specify.dart'`; new private `_numberedStep`, `_bannedTokenLine`; `specStructuralFindings`'s body per (2)+(3); `buildSpecifyBrief` renders the contract; `SpecValidationCapability`'s doc restated). No public SIGNATURE changes: `specStructuralFindings`, `buildSpecifyBrief`, `SpecValidationCapability`, `kSpecGatingRubric` are all unchanged in shape — only the numbered-step finding's message text moves (it still contains `has no numbered steps`). Docs: `packages/grid_assets/extension/rubrics/spec-validation.md` (`## What it checks` restated to the contract the code enforces; the `GATING` / `hard block` / `gated` / `## Bands` prose is untouched, so the pack fences hold). Tests: `spec_committee_test.dart` (a new round-trip group — the shipped exemplar, the ordinal-heading shape, and three negative controls that must still bite: a bulleted plan, an ordinal-only-elsewhere plan, a fence-quoted heading), `specify_stage_test.dart` (the brief renders the contract + exemplar + both ordinal shapes). Extends A13(10) from the placeholder fence to the structure check. the_grid: none.
