## A21 (2026-07-12) — bead `pow-96y`: the DISCOVERY circuit — a nested read-only gather at the spec head whose gate is CITE-THE-OFFENCE; a lens REPORTS and never grades; a missing lane is never a verdict

**Decision:** A17's ratified Status footer named the gap ("A17 checks BEAD-readiness — DISTINCT from DISCOVERY-readiness … a new gap being shaped for its own bead") and A20's REFINED FORWARD footer named the role ("`gather` (the discovery explorers) joins as a third role at the cheap tier"). This is that bead. It ships as a nested `SubCircuitStep` between `readiness-route` and `specify` — the same `CircuitScope` seam `code_review` and `landing` already use, zero engine change — with these autonomous surface calls:
(1) **A lens emits a REPORT, never a letter, and the DECISION is a pure deterministic matrix.** `AgentRole.gather`'s own doctrine (at its declaration in `agent_harness.dart`) is that the role "reads the tree, cites what it finds, and DECIDES NOTHING… It is NOT the home for a cheap JUDGEMENT lane (a lane that emits a verdict letter is grading, not gathering)". That doctrine binds this circuit and is why `DiscoveryLensCapability` is NOT a `CriticCapability` subclass: it emits a `LensReport` (context notes with SOURCES, violations with CITATIONS) and the call is `decideDiscovery`, a pure matrix in `DiscoveryRouteCapability`. Because `56b80f6` removed the amendment that would have carried that rule into the register, it currently lives only in a doc comment — so THIS amendment is where it enters. A binding rule belongs in the register.
(2) **The gate is CITE-THE-OFFENCE, and `gatesTheBead` is the whole of it.** The citable standard is a ratified ADR (its pending `A<n>` amendments included — they bind) UNION an applicable SKILL's instructions: skills TEACH how, ADRs RATIFY the specific, and generic guidance belongs in a skill rather than a proliferating ADR. Three clauses: **no citation, no hold** (an empty `standard` is a vibe — it rides the dossier as a FLAG and can never gate); **the departure clause** (a departure the bead ITSELF declares PASSES — it is judged downstream by `adr-alignment`; only an UNWITTING contradiction gates); **a pattern needs a precedent** (a `pattern` deviation gates only with the precedent NAMED, else it is a flag). The lens is additionally instructed to QUOTE the clause it cites from the file it actually read — the register is edited and amendments are REMOVED, so a remembered `A<n>` is not an existing one. This bead's own round-1 spec was rejected for exactly that error (it cited a phantom `A21(6)` that `56b80f6` had deleted), which is why the instruction is in the prompt and not merely in the reviewer's head.
(3) **A MISSING lens report is a broken LANE, not a verdict.** The route `Rewind`s the silent lens ONCE (`kMaxRegatherRounds`, strictly below the engine's `kMaxReworkRounds` belt) and, at the cap, ADVANCES with the miss recorded LOUDLY in the dossier. It never gates on absence — a gate with no cited offence is precisely what this circuit forbids — and it never wedges the governance track (A17(3): a false HOLD is strictly worse than a wasted specify round). This is a deliberate DEPARTURE from A13(3)'s shared transport stack in exactly one place, stated: the canonical stamped file and the harness result envelope are reused unchanged, but there is NO fail-closed default. A critic's silence is an `F`; a gatherer's silence is MISSING, because a letter has no place on a role that decides nothing.
(4) **`AnchorsCapability` owns the discovery round's FRESHNESS and FAILS LOUD on a write it cannot land** — the A17(8) posture one level down. `ClearCritiqueCapability` wipes `.grid/critique/` only DOWNSTREAM of `specify` (A15(5)), so on a rework round — same worktree, byte-identical node paths — the lenses would otherwise read the previous round's reports. The gather is the discovery circuit's only dep-free step and every lens `dependsOn` it, so its wipe of `.grid/discovery/` IS their guarantee. A gather or dossier write that cannot land in a live worktree is `Failed`, not a silent advance: the lenses would explore blind and the architect would get no dossier, which is this circuit's whole purpose (guards LOUD or GONE).
(5) **Prior art is pulled through the deterministic `StationSearchService`, and an unwired source is reported, never silently empty.** ADR-0001's coupled skill+command rule applied one layer in: the ASSET calls the same UI-drivable service the vended `search` Command adapts, rather than re-deriving cross-store search by inference. READ-ONLY by construction (A37, the A11(3) posture): the service's only store surface is a single-spawn export, this library holds no bd client, and a structural test fences all three properties. A station that composed no `PriorArtSource` gets a dossier line that says NOBODY LOOKED — not "no prior art exists".
(6) **The FIFTH circuit shape is classified on `specify`-presence, not `intake`-presence, and a survivor still IN the ladder MIGRATES FORWARD.** This is the first reshape that did NOT move the circuit's head — `intake` is still the spec circuit's only dep-free step — so A16's classify-by-head-key presence signal no longer discriminates. The discriminator becomes the step DOWNSTREAM of the insertion point: a cursor holding the ladder AND `specify` but no discovery key is a pre-discovery survivor and is FROZEN on `spec_review_v3` (the gather never mounts, its three agents never spawn, its route can never park a building bead); a cursor still IN the ladder adopts the CURRENT shape and gains the discovery circuit, which mounts exactly where it belongs — nothing downstream has run, so there is no spurious spawn and nothing to re-do. This extends A16/A17(11) rather than inventing a parallel mechanism, which is what A16's own Status footer asks of the next reshape (the durable fix — a session STAMPS its circuit-version at mint — is folded into the_grid `tg-w2r`).
(7) **The RUBRICS-IN-BRIEF pull realizes A19's Status footer**, which already names this circuit as the generalization: A19 shows the architect the STRUCTURAL contract; discovery shows it the FULL grading rubrics, through the same `RubricSource` the critics read. The architect specs to the definition the committee grades by.
(8) **`discovery.dart` imports NOTHING from `specify.dart`** — the edge is one-directional, and the rubric IDS the gather pulls arrive as a constructor VALUE (`AnchorsCapability.rubricIds`, wired by `buildCodeRegistry`) rather than as an import. The spec as written prescribed a cyclic import between the two libraries; Dart permits it, but both `circuit_migration.dart` and `respec.dart` carry explicit anti-cycle notes, and config = VALUES / impls = DI (ADR-0008 D-H) gives the same result with the layering intact. This is the one deliberate departure from the ratified plan, recorded here rather than made silently.
**Why:** the architect ALREADY discovers — it stands in a bare worktree. What it lacked was GUIDANCE: it re-derived what we already knew it needed, it never saw the rubrics its spec would be graded by, and a bead that contradicted a decision already made only found that out AT the spec committee, downstream of the most expensive fan-out in the circuit (the ~18-agent round the 2026-07-11 wide run burned per coarse bead). Shifting the check left costs three CHEAP read-only agents and withholds the architect plus the four-critic committee entirely. The gate is deliberately narrow — it holds ONLY on a cited, unacknowledged contradiction of a standard we already ratified — because a governance gate that fires on taste is worse than no gate: it stalls the track and, once distrusted, gets routed around. "Cite the offence, or advance" is the only bar that stays trustworthy without a human in the loop.
